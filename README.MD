# Predict Road Accident Severity using Machine Learning and Israel Road Data

## The Data
Using this project, I will use the Road Traffic Accidents with Casualties from the years 2020–2024 that was published by the Central Bureau of Statistics

- [Data](https://data.gov.il/he/datasets/lamas/2023-puf)
- [Codes](https://www.cbs.gov.il/he/publications/DocLib1/2015/PUF/%D7%AA%D7%97%D7%91%D7%95%D7%A8%D7%94/H20131162AccCodebook.pdf)

## The Goal
Our goal is to predict what will be the Accident Severity based on the data.
